# Reindeers Agency website

Static site (plain HTML, CSS and a little JS, no build step) served by GitHub Pages.

- `index.html`: the whole one-page site
- `assets/css/styles.css`: styles and brand colors
- `assets/js/main.js`: mobile menu and scroll reveal
- `assets/img/`: logos, team photos and case study images (from the 2026 credentials deck)
- `CNAME`: the custom domain GitHub Pages serves (`reindeers.agency`)

To edit text, change `index.html` and push to `main`; GitHub Pages redeploys automatically.
